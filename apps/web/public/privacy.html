뽀모도로(Wannabe Ketchup) 개인정보처리방침

시행일: 2026년 11월 28일

Wannabe Ketchup 운영팀(이하 "운영팀")은 「개인정보 보호법」에 따라 이용자의 개인정보를 보호하고 관련 고충을 원활하게 처리하기 위해 다음과 같이 개인정보처리방침을 공개합니다. 뽀모도로는 회원가입 없이 쓰는 서비스이며, 이용하기 위해 이름·전화번호·이메일 주소를 입력할 필요가 없습니다.

1. 처리하는 개인정보의 항목과 수집 방법

  • 서비스 이용 시 자동 생성·수집: 참여자 ID(무작위 값), 세션 쿠키, IP 주소, 접속 일시, 요청 주소, 브라우저 정보(User-Agent)
  • 방 이용 시 이용자가 입력: 닉네임, 상태 메시지, 채팅 메시지. 이 정보는 같은 방의 다른 참여자에게 보이므로 개인정보나 민감한 내용을 적지 않도록 주의해 주세요.
  • 피드백을 보낼 때: 피드백 내용과 첨부한 사진·동영상, 그리고 접수 시각·IP 주소·참여자 ID·브라우저 정보(자동으로 함께 전송)
  • 운영팀에 메일로 문의할 때: 보낸 사람 메일 주소, 문의 내용

2. 처리 목적

  • 방 참여, 타이머 동기화, 채팅 등 서비스 제공
  • 장애 확인, 부정 이용 방지 등 서비스 운영과 보안
  • 피드백 확인과 버그 재현
  • 문의와 개인정보 열람·삭제 등 요청 처리

4. 파기 절차와 방법

  • 보유 기간이 지나거나 처리 목적을 달성해 필요 없어진 개인정보는 지체 없이 파기합니다. 닉네임과 상태 메시지는 방에서 나갈 때, 채팅 메시지는 방이 삭제될 때 서버 메모리에서 지워지고, 만료된 세션 정보는 10분 안에 지워집니다. 로그는 보유 기간이 지나면 자동으로 삭제됩니다. 피드백 메일은 운영팀이 접수 후 90일이 지나면 메일함에서 삭제하고, 문의 메일은 처리를 마친 후 90일이 지나면 삭제합니다. 전자 파일은 복구할 수 없는 방법으로 삭제합니다.
