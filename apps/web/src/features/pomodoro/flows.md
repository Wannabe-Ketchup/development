## P-A. 참가자 목록 탐색

대상: 키보드 사용자 / 스크린 리더 사용자
진입 조건: 방에 입장해 참가자(본인 1명 + 타인 2명) 상태가 로드된 뽀모도로 화면

| 단계 | 포커스 위치 (role "name")                | 동작                       | 예상 결과 / ARIA 발화                                                 |
| ---- | ---------------------------------------- | -------------------------- | --------------------------------------------------------------------- |
| 1    | (초기 진입)                              | `/pomodoro?roomId=r1` 접속 | list "참가자 목록"이 노출되고 listitem이 3개로 드러난다               |
| 2    | 첫 번째 listitem (본인)                  | SR 탐색                    | 접근 가능한 이름이 "나,"로 시작한다                                   |
| 3    | 2·3번째 listitem (타인)                  | SR 탐색                    | 빈 상태 메시지는 접근성 트리에 노출되지 않고, 수정 버튼도 트리에 없다 |
| 4    | button "상태 메시지 수정" (본인·빈 상태) | focus                      | 포커스 가능 상태(opacity 1)로 노출된다                                |
| 5    | list "참가자 목록"                       | ariaSnapshot               | 접근성 트리 스냅샷이 기준(`pomodoro-participants.txt`)과 일치한다     |

e2e 파일: `apps/web/e2e/pomodoro-accessibility.spec.ts` › `P-A. 참가자 목록 탐색`

## P-B. 음악 재생/중지

대상: 키보드 사용자 / 스크린 리더 사용자
진입 조건: 뽀모도로 화면 진입 (`mockEnterRoomOnly` 상태)

| 단계 | 포커스 위치 (role "name") | 동작    | 예상 결과 / ARIA 발화                                                  |
| ---- | ------------------------- | ------- | ---------------------------------------------------------------------- |
| 1    | (초기 진입)               | —       | button "음악 재생"이 노출된다                                          |
| 2    | button "음악 재생"        | click   | 버튼 라벨이 "음악 중지"로 바뀌어 현재 재생 상태를 전달한다             |
| 3    | (장식 요소)               | SR 탐색 | 재생 중 음표 애니메이션은 접근성 트리에 노출되지 않는다(`aria-hidden`) |

e2e 파일: `apps/web/e2e/pomodoro-accessibility.spec.ts` › `P-B. 음악 재생/중지`
