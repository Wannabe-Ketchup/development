| 단계 | 포커스 위치 (role "name") | 동작            | 예상 결과 / ARIA 발화                                                                                                                                               |

| 1    | textbox "초대 코드"       | 빈 값으로 Enter | input에 `aria-invalid="true"`, `aria-describedby="room-entry-error"`가 설정되고 `#room-entry-error` 영역에 "초대 코드를 입력해 주세요."가 노출된다 (`role="alert"`) |

## H-F. 사용 설명서를 읽는다

대상: 키보드 사용자 / 스크린 리더 사용자
진입 조건: 홈 경로(`/`), 지원 화면(가로)

| 단계 | 포커스 위치 (role "name") | 동작            | 예상 결과 / ARIA 발화                                                                                                                                                                                               |
| ---- | ------------------------- | --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | button "사용 설명서"      | Enter           | dialog "워너비케챱 사용 설명서"가 열리고 포커스가 dialog 안으로 이동한다. 표지 없이 차례와 첫 장이 펼쳐진 채로 보이고, 색인·이전/다음 버튼과 "1 / 5"가 함께 나타난다. `aria-live="polite"`로 "1 / 5, 차례"를 알린다 |
| 2    | dialog 안                 | ArrowRight      | 다음 장으로 넘어가고 "2 / 5, 뽀모도로란?"을 알린다. 포커스는 그대로다                                                                                                                                               |
| 3    | button "FAQ"(책갈피)      | Enter           | 마지막 장인 FAQ 장으로 넘어가고 "5 / 5, 자주 묻는 질문"을 알린다. 넘김이 끝나면 포커스가 heading "자주 묻는 질문"(`tabindex="-1"`)으로 이동한다. 책갈피에 `aria-current="true"`, button "다음 장"은 비활성화된다    |
| 4    | button "사용 설명서"      | Enter 후 Escape | dialog가 닫히고 button "사용 설명서"로 포커스가 돌아온다                                                                                                                                                            |

- 이전/다음 버튼과 방향키로 넘기면 포커스는 그대로 두고 장 번호와 제목만 알린다. 책갈피는 고른 장을 바로 읽도록 그 장 제목으로 포커스를 옮긴다.
- 장이 넘어가는 중에는 추가 넘김을 무시하지만 Esc·닫기·바깥 클릭은 언제든 동작한다.
- 모션 줄이기 설정에서는 넘김 애니메이션 없이 바로 다음 장이 나타난다.

e2e 파일: `apps/web/e2e/home-accessibility.spec.ts` › `H-F. 사용 설명서를 읽는다`
