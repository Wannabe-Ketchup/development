## H-A. 홈에 처음 도착해 공부를 시작한다

대상: 키보드 사용자 / 스크린 리더 사용자
진입 조건: 홈 경로(`/`) 첫 진입

| 단계 | 포커스 위치 (role "name") | 동작     | 예상 결과 / ARIA 발화                                                                     |
| ---- | ------------------------- | -------- | ----------------------------------------------------------------------------------------- |
| 1    | (초기 진입)               | `/` 접속 | button "공부 시작"이 노출된다                                                             |
| 2    | button "공부 시작"        | Space    | group "어디서 공부할까요?"가 열리고 그룹 안 button "새로운 방 만들기"로 포커스가 이동한다 |

## H-B. 새로운 방을 만든다

대상: 키보드 사용자 / 스크린 리더 사용자
진입 조건: 홈에서 "공부 시작" 눌러 방 선택 그룹이 열린 상태

| 단계 | 포커스 위치 (role "name") | 동작        | 예상 결과 / ARIA 발화                                                                            |
| ---- | ------------------------- | ----------- | ------------------------------------------------------------------------------------------------ |
| 1    | button "새로운 방 만들기" | click/Enter | 방 생성 API 호출 시작                                                                            |
| 2    | 동일 버튼                 | (대기)      | 라벨이 "방 만드는 중..."으로 바뀌고 `aria-busy="true"`, `aria-disabled="true"`로 상태를 노출한다 |

e2e 파일: `apps/web/e2e/home-accessibility.spec.ts` › `H-B. 새로운 방을 만든다`

## H-D. 잘못된 초대 코드로 에러를 받는다

대상: 키보드 사용자 / 스크린 리더 사용자
진입 조건: 초대 코드 입력 화면이 열린 상태

| 단계 | 포커스 위치 (role "name") | 동작            | 예상 결과 / ARIA 발화                                                                                                                                               |
| ---- | ------------------------- | --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | textbox "초대 코드"       | 빈 값으로 Enter | input에 `aria-invalid="true"`, `aria-describedby="room-entry-error"`가 설정되고 `#room-entry-error` 영역에 "초대 코드를 입력해 주세요."가 노출된다 (`role="alert"`) |
| 2    | button "입장하기"         | 빈 값에서 click | 포커스가 textbox "초대 코드"로 복원되어 스크린 리더가 invalid 상태와 에러 메시지를 다시 읽는다                                                                      |

e2e 파일: `apps/web/e2e/home-accessibility.spec.ts` › `H-D. 잘못된 초대 코드로 에러를 받는다`

## H-E. 공부 준비를 취소한다

대상: 키보드 사용자 / 스크린 리더 사용자
진입 조건: "공부 시작" 눌러 방 선택 그룹이 열려 있거나 초대 코드 입력 화면이 열린 상태

| 단계 | 포커스 위치 (role "name")     | 동작   | 예상 결과 / ARIA 발화                                       |
| ---- | ----------------------------- | ------ | ----------------------------------------------------------- |
| 1    | 방 선택 그룹 내 포커스        | Escape | 그룹이 닫히고 button "공부 시작"으로 포커스가 복귀된다      |
| 2    | 초대 코드 입력 화면 내 포커스 | Escape | 입력 화면이 닫히고 button "공부 시작"으로 포커스가 복귀된다 |

e2e 파일: `apps/web/e2e/home-accessibility.spec.ts` › `H-E. 공부 준비를 취소한다`
