# 개인정보 처리(privacy) 도메인

서비스가 다루는 개인정보를 어떻게 알리고 얼마나 보관하는지 정리한다. 구현 방법이 아니라 **무엇이 참이어야 하는지**를 적는다.

## 용어

| 용어             | 뜻                                                                        |
| ---------------- | ------------------------------------------------------------------------- |
| 개인정보처리방침 | 서비스가 처리하는 개인정보의 항목·목적·보관 기간 등을 공개하는 문서       |
| 접속 정보        | 요청과 함께 자동으로 남는 IP 주소, 참여자 ID, 요청 주소, 브라우저 정보 등 |

## 공개

- 개인정보처리방침은 `/privacy.html`에 공개한다. 이 주소는 Google 인증 플랫폼(피드백 메일 OAuth 앱)의 브랜딩에도 쓴다.
- 홈, 작은 화면 안내, 피드백 모달에서 처리방침을 열 수 있다. 방 연결과 작성 중인 내용을 지키기 위해 새 탭으로 연다.
- 처리방침에는 시행일과 개정 이력을 둔다.

## 동의

- 서비스 제공에 필요한 정보(세션 쿠키, 참여자 ID, 접속 정보, 피드백)는 동의를 받지 않고 처리방침으로 알린다. 근거는 개인정보 보호법 제15조 제1항 제4호(계약 이행)다.
- 피드백은 보내기 전에 접속 정보가 함께 간다는 것을 화면에서 알린다. 별도 동의 체크박스는 두지 않는다.
- 피드백 메일을 해외 서버(Gmail)에 보관하는 것은 처리방침에 국외 이전 사항을 공개하는 것으로 한다(제28조의8 제1항 제3호).

## 보관 기간

처리방침에 적는 값이다. 아래 값을 코드나 설정에서 바꾸면 처리방침도 같은 작업에서 고친다.

| 정보                                                 | 보관 기간                                                                                                                     | 값이 정해진 곳                                  |
| ---------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------- |
| 세션 쿠키, 참여자 ID                                 | 참여자 ID는 발급 후 24시간 동안 쓴다. 세션은 마지막 요청 후 24시간에 만료되고, 만료된 세션은 10분 안에 서버 메모리에서 지운다 | `Session.TTL_MS`, `session.config.ts` 정리 주기 |
| 닉네임, 상태 메시지                                  | 방에서 나갈 때까지                                                                                                            | `pomodoro.md` 참여자                            |
| 채팅 메시지                                          | 방이 삭제될 때까지(방이 빈 뒤 30분). 방마다 최근 100개만 남긴다                                                               | `pomodoro.md` 방 삭제·채팅                      |
| 서버 로그(IP, 참여자 ID, 요청 주소)                  | 30일                                                                                                                          | api 로거 `maxFiles`                             |
| 로그 분석 사본(Loki, 서버 로그만)                    | 90일                                                                                                                          | `staging/loki/loki.yml` `retention_period`      |
| 웹 서버 접근 기록(nginx, IP·요청 주소·브라우저 정보) | 90일                                                                                                                          | `production/logrotate/nginx`                    |
| 피드백 메일(내용·첨부·IP·참여자 ID·브라우저 정보)    | 접수 후 90일(운영팀이 직접 삭제)                                                                                              | 운영 절차                                       |
| 문의 메일(보낸 사람 메일 주소, 문의 내용)            | 처리를 마친 후 90일(운영팀이 직접 삭제)                                                                                       | 운영 절차                                       |

## 보호책임자

- 개인정보 보호책임자는 "Wannabe Ketchup 운영팀"이고, 연락처는 공용 메일이다.

## 범위 밖

- 서비스 약관
- 명시적 동의 체크박스
- 피드백 메일 자동 삭제 장치
