## 8. 테스트 계획

파일 위치: api는 `apps/api/test/<모듈>/<계층>/<대상>.spec.ts`(통합은 `.integration.spec.ts`), web은 대상 파일 옆 `<대상>.test.ts(x)`.

| 계층           | 파일                                                   | `it` 문장 | 깨지면 깨지는 규칙 |
| -------------- | ------------------------------------------------------ | --------- | ------------------ |
| Domain 단위    | `test/<모듈>/domain/<대상>.spec.ts`                    |           |                    |
| Service 통합   | `test/<모듈>/service/<대상>.integration.spec.ts`       |           |                    |
| Controller E2E | `test/<모듈>/controller/<대상>.controller.spec.ts`     |           |                    |
| Web            | `apps/web/src/features/<도메인>/.../<대상>.test.ts(x)` |           |                    |
